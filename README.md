## Description

A simple, and true to me website I made for learning `html` and introducing myself! It has a nice lock-screen, a nice home-screen, inspired by Windows 10, shortcuts on the taskbar for contacting me and for downloading my projects, and a few "apps" which are just `iframes` in a window div that is resizeable and has an nice transparency effect!

## Features

- A WebOS aesthetic (Windows 10-ish), with a pseudo-lockscreen, taskbar with my socials and my projects!
- Desktop icons with an `ABOUTME.md` file, where you can read... about me!
- A simple `iframe` web browser, a Minecraft app (one of my fav games!) which is an `iframe` for [Minecraft Classic](https://classic.minecraft.net)
- An `iframe` code editor, for [LiveCodes](https://livecodes.io)

## Tech Stack

Nothing complicated, just simple `HTML` with `CSS` and `JavaScript`!

## Getting Started

Just open the [website](thebluefirestudios.github.com/my-portfolio) and browse!, It even has a Web Browser in it! (It uses `iframe` so very few websites actually load)

If you wish to run this locally, just download the repository or run:
```bash
git clone https://github.com/THEbluefirestudios/my-portfolio.git
```
then open the `index.html` file, it is a very basic file so that is all you need!
